# LightDrop Product Requirements Document

## Vision

LightDrop makes nearby computers feel like a single workstation.

Whether you're moving a screenshot to a corporate laptop, sending logs to your MacBook, or sharing files between development machines, LightDrop should require no thought.

Run the application on each machine and they automatically discover each other over the local network.

Sharing should feel instantaneous.

No cloud.

No accounts.

No installation.

No configuration.

## Problem

Developers often work across multiple computers:

- Personal desktop
- Corporate laptop
- MacBook
- Mini PC
- Home server

Moving files between them is surprisingly painful, typically involving cloud storage, email, messaging apps, USB drives, or SCP.

These approaches are either too slow, require internet connectivity, or are inappropriate for confidential work.

LightDrop provides a lightweight local-first alternative.

## Non Goals

LightDrop is not:

- Dropbox
- Syncthing
- Google Drive
- Remote Desktop
- SSH
- A synchronization service
- A backup solution

It is a lightweight local companion for nearby devices.
